# macOS 构建与限制说明

本文档集中记录 macOS 应用的兼容性、发布限制及运行注意事项。

## 构建与验证范围

- GitHub Actions 使用 macOS 构建器编译 SwiftUI 图形界面与 Go 核心。
- GUI 和核心分别编译 arm64 与 x86_64，再合并为通用架构应用。
- CI 执行 Go 测试、二进制架构检查和 macOS 代码签名校验。
- CI 编译成功不等于已通过真实 Amazon Quick 账号登录、联网聊天或长时间稳定性验证。
- 构建产物包括 ZIP 与 DMG，可在 Actions Artifacts 或 macos-preview 预览发布中取得。

## 运行系统

- 最低目标为 macOS 13，包含 Apple Silicon 和 Intel 两种架构。
- 界面使用 SwiftUI 和 AppKit，无法作为 Linux、Windows GUI 运行。
- 应用没有自动启动代理，需要在管理窗口或菜单栏选择“启动代理”。
- 关闭管理窗口后，应用及菜单栏仍可继续运行。
- 退出应用时会停止由该应用启动的代理进程。外部终端启动的独立代理进程不归应用管理。

## 应用签名与安装

- 自动构建使用 ad-hoc 签名，没有 Apple Developer ID 签名，也没有 Apple notarization 公证。
- 首次打开下载的应用时，macOS 可能提示开发者无法验证。可通过系统设置中的“隐私与安全性”检查并按需允许运行。
- 不建议关闭系统全局安全策略来解决 Gatekeeper 提示。
- 若用于公开大规模分发，应加入 Developer ID 签名、公证和完整的安装测试流程。

## 配置与数据

- 配置文件：~/Library/Application Support/QuickProxy/config.json。
- SQLite 账号数据库：~/Library/Application Support/QuickProxy/data/quickwork.db。
- 登录凭据可能包括 access token、refresh token、client secret。不要分享数据库、完整配置或含敏感回调地址的日志。
- 应用设置界面可修改本机监听地址、默认模型和会话复用。其他高级字段需要在 config.json 中修改。
- GUI 限制监听地址为 127.0.0.1 或 localhost，避免在界面中误开放远程访问。
- 修改配置后需停止并重新启动代理才能生效。
- 旧版 CLI 若在其他目录使用配置与数据库，不会被自动导入。需要迁移时先备份，并在代理停止后复制文件。

## 上游与功能限制

- 登录依赖 Amazon Quick OAuth 服务和本机浏览器回调。账号资格、上游接口变更或服务限制可能影响登录和反代。
- 上游的 API、模型名称、会话机制和使用规则以实际服务为准。
- 多账号采用现有 Go 核心的轮询策略，图形界面不改变账号分配算法。
- 本项目为非官方工具，与 Amazon/AWS 没有从属或授权关系；使用时应遵守上游服务条款。
- 当前只提供已经实现的 OpenAI 兼容端点，不能据此推断支持全部 OpenAI API 功能。
- 若端口被其他程序占用，本应用无法接管已有进程。请停止冲突服务或修改监听端口。

## 用户数据与日志

- 账号令牌存放在本机数据库；请求内容经由核心程序发送到 Amazon Quick 上游服务。
- 进程日志可能包含账号名称、错误信息和运行上下文。复制日志前应检查并删除敏感内容。
- 应用内日志为内存中的最近输出，最多保留约 60–80 千字符；退出应用后不持久化。


## 图形界面配置

- 概览中的状态与地址只反映由 QuickProxy.app 启动的代理进程。
- “代理设置”可分别选择监听主机、输入 1–65535 的端口，并设置默认模型和会话复用。
- “API 密钥”可以添加已有 Key，或生成本地随机 Key；列表中只显示密钥末尾八位。
- 单击“保存配置”写入本机 config.json；服务运行时需重启才会重新读取配置。
- “保存并重启”会先结束当前代理进程，再使用新配置启动代理；正在进行中的 API 请求可能因此中断。
- 关闭 API 鉴权的方法是移除列表中全部 Key 并保存。
- 用户复制密钥后，内容进入系统剪贴板。请注意剪贴板历史工具及其他拥有剪贴板访问权限的软件。
- 通过图形界面输入的 API Key 不应包含空白字符；同一份配置中不能有重复密钥。
- 本界面不提供密钥使用量统计和账号级配额控制，这些需要另行设计。
- 已通过 GitHub Actions 验证编译与打包。浏览器登录和实际上游 API 调用仍需使用有效账号测试。


## 实际模型观测

- 具体模型 ID 来自真实成功请求中的上游 `turn_usage` 数据，不能仅凭请求档位推断。
- 未执行过成功请求、上游没有返回相关字段或后端未更新时，`/v1/models` 只展示已配置的档位。
- 观测记录为历史事实，无法保证上游下次使用相同模型。`/v1/models` 把具体模型 ID 映射到上次观测对应的 agent mode；不具备底层模型强制选择能力。
- 记录路径：`~/Library/Application Support/QuickProxy/data/observed-models.json`。文件不包含 API Key 或会话内容。
- CC Switch 获取模型需使用 `http://127.0.0.1:<监听端口>/v1` 和正确的本地 API Key。
- 当前 Go 服务对聊天请求使用 OpenAI Chat Completions 协议；直接作为 Anthropic Messages API 服务接入 Claude Desktop 时仍需协议转换层。
